# PROBA Telegram Mini App

Мобильный прототип полного цикла домашней сдачи анализов: покупка и активация PROBA Kit, вызов курьера, выбор исследований с мгновенным пересчётом цены, передача заявки в лабораторию, результаты, консультация проверенного врача, рекомендации и отдельная витрина товаров.

- Production сейчас: [защищённый временный адрес](https://proba.64-188-58-140.nip.io)
- Основной домен: [probaclinical.ru](https://probaclinical.ru) — переключится после первичной публикации DNS-зоны
- Telegram: [@probaclinicalbot](https://t.me/probaclinicalbot)
- Запуск в Telegram: кнопка `Открыть PROBA` и Main Mini App включены на временном production-адресе.
- В Telegram приложение запрашивает полноэкранный режим, отключает вертикальный свайп закрытия по содержимому и увеличивает макет iPhone до доступной высоты экрана.
- Аватар и favicon: `public/assets/proba/proba-bot-logo.png` — красная капля крови на белом фоне.
- Статус: интерактивный frontend-прототип; реальные медицинские данные, оплата и интеграции не подключены.

## Что можно пройти в прототипе

- Купить PROBA Kit или активировать уже купленный набор по коду.
- Выбрать отдельные анализы либо готовую панель; итог меняется сразу.
- Выбрать проверенную лабораторию и отправить ей заявку.
- Выбрать день и часовой слот курьера, затем открыть трекинг образца.
- Открыть результаты и увидеть статус каждого биомаркера.
- Дать выбранному врачу ограниченный доступ к результатам, записаться на консультацию и открыть демо-рекомендацию.
- Купить рекомендованный товар либо открыть витрину независимо от врача.
- Запланировать новый цикл через 8 или 12 недель либо через 6 месяцев; следующий набор подтверждается отдельно, цикл можно пропустить.
- Открыть демонстрационный кабинет лаборатории, принять заявку и опубликовать результаты.

Все данные, оплата, медицинские статусы и партнёры в прототипе демонстрационные и не сохраняются.

```bash

```

```bash
npm run check:runtime
npm run build
```

Готовая статическая сборка создаётся в `dist/client`.

## Предлагаемая продуктовая модель

Цена разделена на понятные части: набор, логистика, лабораторные исследования и консультация. В MVP не стоит прятать анализы в безлимит: себестоимость сильно зависит от панели, а обещание «всё включено» быстро превращает маржу в музейный экспонат.

- PROBA Kit: 2 490 ₽.
- Курьер: от 490 ₽; в подписке включён один забор и доставка образца за цикл.
- Анализы: по партнёрскому прайсу выбранной лаборатории; в прототипе используется ориентир среднего московского рынка.
- Обработка заявки: 190 ₽ только в разовом сценарии.
- Консультация врача: 1 490–1 990 ₽ в зависимости от специализации.
- PROBA Cycle: 2 690 ₽ за подтверждённый цикл, включая набор, курьера, трекинг, напоминания и скидку 10% на исследования.

Подписка устроена как план повторного цикла, а не как скрытое автосписание: за 7 дней сервис напоминает, за 3 дня показывает сумму, и только после подтверждения готовит набор. Пользователь может бесплатно пропустить цикл или поставить план на паузу.

## Рекомендуемая архитектура MVP

```text
Telegram Bot / Mini App
        |
        v
API и управление циклами
   |        |         |
   v        v         v
заказы   курьеры   платежи
   |
   v
адаптеры лабораторий <-> кабинет лаборатории
   |
   v
результаты и динамика -> согласие пациента -> кабинет врача
                                             |
                                             v
                                  рекомендация -> витрина
```

Для первой версии достаточно одного модульного backend-приложения с PostgreSQL, очередью задач и отдельными ролями клиента, лаборатории, врача и оператора. Интеграции с лабораториями лучше делать через адаптеры: API, защищённая загрузка CSV/PDF либо ручной кабинет как временный канал. Медицинские данные, согласия и журналы доступа должны храниться отдельно от маркетинговых событий.

## Границы безопасного сценария

- Врач видит только те результаты, на которые клиент дал явное согласие.
- Проверка врача и лаборатории выполняется до публикации профиля.
- Рекомендация врача визуально и юридически отделена от коммерческой витрины.
- Пользователь может купить товар отдельно; рекомендация не создаёт обязательство покупки.
- Мини-приложение показывает ориентиры и динамику, но не ставит диагноз.
- До запуска понадобится юридическая проверка телемедицины, дистанционной торговли, рекламы медизделий/БАДов, обработки специальных категорий персональных данных и условий транспортировки биоматериала.
